# Security policy

## Supported versions

opengrid is pre-1.0. Security fixes go into the latest `0.x` release of
`@casoon/opengrid`, `@casoon/opengrid-mcp` and the `opengrid-*` crates; older
releases are not patched, update to the current one.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead: on
the repository page choose **Security → Report a vulnerability**
(<https://github.com/casoon/opengrid/security/advisories/new>).

Include the affected package and version, what an attacker can do, and a
minimal reproduction if you have one.

## What to expect

This is a small project with one maintainer. You get an acknowledgement within
about a week; a confirmed issue is fixed in a patch release and credited in the
advisory and the changelog unless you prefer otherwise.
