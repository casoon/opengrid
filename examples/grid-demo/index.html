opengrid — a grid over 100,000 rows

An <opengrid-grid> driven by the local WASM engine. The page loads a data set, hands the engine in as a provider and renders a virtual window: about 40 DOM rows standing in for 100,000 logical ones, recycled as you scroll. Fully operable from the keyboard, following the WAI-ARIA grid pattern. Above the table sits a filter row — one operator and one value per column, applied with Enter.

Generate the 100k data set (optional)

The 100k data set is not checked in. Without it the demo falls back to the small conformance data set. To generate it, from the repository root: 

mkdir -p target/grid-demo
cargo run -p xtask -- gen-orders --rows 100000 --seed 1 --out target/grid-demo/orders-100k.csv
just serve-demo   # then open http://127.0.0.1:8080/examples/grid-demo/

The query's columns (id,customer,country,amount,qty) are a subset of the ten-column schema xtask generates. The default sort key is the first column (id, ascending), because paging needs a total order (rule S6).
