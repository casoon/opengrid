opengrid — a pivot in the browser

Rows: country · columns: year · measures: sum of quantity, and a count. No server: the engine runs in a worker over the conformance dataset and answers the pivot as n+1 ordinary queries — the same answer the server gives (index.html), which the conformance suite checks.

Every number is a button to the rows it is made of: the pivot fires opengrid-drill-down with the cell's filter, and this page shows the rows in a grid below. The button over the grid leads back to the cell.

Serve the page with just serve-demo.
