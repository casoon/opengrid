opengrid — a pivot is one request

Rows: country · columns: year · measures: sum of quantity, and a count. The whole thing is one request to POST /pivot/orders. PostgreSQL answers it as a single GROUPING SETS statement and the local engine as n+1 ordinary queries — with the same result, which the conformance suite checks.

Start the server with cargo run -p opengrid-server -- examples/remote-demo/opengrid.toml and serve the page with just serve-demo. This demo needs the server: the pivot has no client-side path yet.
