opengrid — Pivot (Plan-Punkt 32)

Zeilen: Land · Spalten: Jahr · Kennzahlen: Summe Menge und Anzahl. Die ganze Abfrage ist ein Request an POST /pivot/orders; PostgreSQL beantwortet sie als eine einzige GROUPING SETS-Anweisung, die lokale Engine als n+1 gewöhnliche Queries — mit demselben Ergebnis.

Server starten: cargo run -p opengrid-server -- examples/remote-demo/opengrid.toml, Seite ausliefern mit just serve-demo.
