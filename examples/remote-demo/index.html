opengrid — the data comes from a server

The same <opengrid-grid>, but the rows do not come from the engine in this tab. They come over POST /query/orders from a running opengrid-server. The browser sends the query AST — never SQL.

Token

Each token stands for a country in the server's configuration, and the server appends a mandatory filter from it to every query. The two tokens therefore see different rows while the page sends exactly the same request — the page cannot opt out, which is the point.
