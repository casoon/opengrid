opengrid — Table Mode

<opengrid-table> is the display variant: an ordinary <table> with its full semantics, so copying, the browser's own find-in-page and a screen reader all behave exactly as they do on any other table. No virtualization, no roving tabindex. The header buttons sort a column.

For a table that is worked with — selection, editing, a hundred thousand rows — <opengrid-grid> is the right element (see examples/grid-demo/).

Serve it with just serve-demo, then open this page.
