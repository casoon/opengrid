opengrid — Table Mode

<opengrid-table> ist die Anzeige-Variante: ein ganz normales <table> mit voller Semantik — Kopieren, Browser-Suche und Screenreader funktionieren wie bei jeder Tabelle. Keine Virtualisierung, kein Roving Tabindex. Die Kopfzeilen-Buttons sortieren eine Spalte.

Für eine Tabelle, mit der gearbeitet wird — Auswahl, Bearbeiten, hunderttausend Zeilen — ist <opengrid-grid> das richtige Element (siehe examples/grid-demo/).

Ausliefern mit just serve-demo, dann diese Seite öffnen.
