opengrid — Worker-Demo mit 100 000 Zeilen

Dieselbe Oberfläche wie die Grid-Demo, aber die Engine läuft in einem Web Worker (createWorkerProvider): der Main Thread behält DOM, Events und Rendering, der Worker übernimmt Ingest, Filter, Sortierung und Gruppierung. Die Zahl 0 zählt requestAnimationFrame-Frames und zeigt, dass die Oberfläche während einer großen Query weiterläuft. Bedienung vollständig per Tastatur nach dem WAI-ARIA Grid Pattern; über der Tabelle sitzt die Filterzeile (Operator + Wert je Spalte, Enter wendet an).

100k-Datensatz erzeugen (optional)

Der 100k-Datensatz wird nicht eingecheckt. Ohne ihn lädt die Demo den kleinen Conformance-Datensatz. Zum Erzeugen aus dem Repo-Wurzelverzeichnis: 

mkdir -p target/worker-demo
cargo run -p xtask -- gen-orders --rows 100000 --seed 1 --out target/worker-demo/orders-100k.csv
just wasm-build            # Engine-Modul
just wasm-build-components # Element-Modul
just serve-demo            # dann http://127.0.0.1:8080/examples/worker-demo/ öffnen

Die Spalten der Query (id,customer,country,amount,qty) sind eine Teilmenge des 10-spaltigen Schemas aus xtask. Der Standard-Sortierschlüssel ist die erste Spalte (id, aufsteigend): Seiten brauchen eine totale Ordnung (Regel S6).
